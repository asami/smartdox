## Goal

Ensure every generated `metadata/rdf/graph.json` node has a deterministic,
non-empty display label. In particular, language-tagged and typed literal nodes
with empty lexical values must receive a valid display label generated by
SmartDox.

The observed consumer evidence is that SimpleModeling.org generated empty
labels for `literal::en` and `literal::ja` nodes, and Cozy public finalization
rejected those empty labels. The correction belongs to SmartDox; Cozy validation
must not be relaxed or described as defective.

## Scope

In scope:

- specify deterministic fallback display semantics for empty language-tagged,
  typed, and plain literal values;
- implement only the SmartDox RDF graph projection that produces the fallback
  labels;
- add Given/When/Then executable specifications for empty language-tagged,
  typed, and plain literal variants; and
- preserve RDF node IDs, triples, JSON-LD/Turtle semantics, ordinary nonempty
  literal labels, and graph ordering.

Out of scope:

- Cozy code or specifications;
- SimpleModeling.org wrappers or source;
- site builds or production publishing;
- compatibility-validation relaxation; and
- unrelated dashboard or rendering refactors.

## Acceptance Dependency

After SmartDox implementation and focused regression acceptance, separately
authorize a SimpleModeling.org site regeneration and revalidate its generated
RDF graph output with a direct all-node nonempty-label scan. This stage owns
the downstream finalizer run, metadata-only inventory/hash evidence, and
wrapper failure-path acceptance transferred from Cozy Phase 29 `BM29-03`; no
Cozy restart is required because Phase 29 is closed on its bounded
implementation contract. Managed Textus BoK reader acceptance
and the CNCF Phase 70 activation dependency are downstream consumer-integration
handoffs owned by Textus BoK, and are nonblocking for this Phase.

## Completion Criteria

This Phase completes only when the fallback display semantics are specified and
implemented in SmartDox, the empty language-tagged, typed, and plain literal
variants have Given/When/Then executable coverage, focused regression passes,
and the generated SimpleModeling.org output is revalidated with every graph
node label non-empty while the Cozy finalization inventory/hash/allowlist and
wrapper failure-path evidence are recorded and the listed RDF and ordering
invariants remain true. Managed Textus BoK reader acceptance and CNCF Phase 70
activation remain nonblocking downstream consumer handoffs.
